## Built with

Plain HTML, CSS and JavaScript, with no frameworks or build step. The contact form uses [Formspree](https://formspree.io/), and the site is hosted on GitHub Pages.

## Structure

```
├── index.html            Single-page portfolio
└── assets/
    ├── css/styles.css    Styles (dark theme, responsive)
    ├── js/app.js         Mobile menu, active section, back-to-top button
    ├── icons/            Skill logos (SVG)
    ├── images/           Project screenshots (WebP)
    └── documents/        CV (PDF)
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 3000
```
